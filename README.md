# Word Garden 🌱

전공 영어 단어를 학습하고 복습하는 정적 웹 앱입니다. 8개 전공에 걸쳐 2,000개 단어를 제공하며, 각 단어에서 뜻과 예문을 확인할 수 있습니다.

- 전공별 단어 세트, 학습 이어하기, 출석 달력
- 복습 목록, 즐겨찾기, 학습 기록 내보내기
- 단어 문제를 맞혀 말을 움직이는 체스와 AI 난이도 3단계

## 로컬 실행

Node.js가 설치된 상태에서 이 폴더를 열고 다음을 실행하세요. Windows에서는 `로컬 실행.cmd`를 실행해도 됩니다.

```sh
node serve.mjs
```

브라우저에서 [http://127.0.0.1:4175](http://127.0.0.1:4175)를 여세요. JavaScript 모듈을 사용하므로 `index.html`은 HTTP 서버를 통해 열어야 합니다.

## GitHub Pages에 배포하기

이 폴더의 파일을 GitHub 저장소 루트에 올린 뒤, 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하세요. 소스는 `main` 브랜치의 `/ (root)`로 지정합니다. 별도 빌드 명령이나 패키지 설치가 필요하지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `styles.css`, `garden.css` | 화면과 스타일 |
| `app.js`, `data.js` | 앱 동작과 전공별 단어 데이터 |
| `chessEngine.js` | 체스 규칙과 상대 AI |
| `store.js`, `sync.js`, `config.js` | 학습 기록 저장과 서버 연동 설정 |
| `mascot.png`, `icon.svg` | 새싹 마스코트와 사이트 아이콘 |
| `serve.mjs`, `로컬 실행.cmd` | 로컬 미리보기 |

학습 기록은 현재 접속 주소의 브라우저 저장소에 보관됩니다. GitHub Pages나 다른 주소에서 열면 기존 주소의 학습 기록이 자동으로 이전되지 않습니다. 서버 동기화 주소는 기본값에서 비어 있습니다.
